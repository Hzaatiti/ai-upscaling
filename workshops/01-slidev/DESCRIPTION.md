Title: "SlideV"

Description: In this workshop you will learn about the Slidev framework to make interactive presentations. We will cover several use cases: getting familiar with the slidev syntax, building an interactive
scientific demo, making scripts to pull data and update your slides automatically, collaborate on your slides using github.
